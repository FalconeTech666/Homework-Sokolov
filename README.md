# Homework Sokolov

Python learning repository with practice tasks from early programming lessons.
The project contains small exercises for syntax, conditions, loops, strings,
lists, collections and functions.

## Stack

- Python

## Contents

- Basic syntax and input/output.
- Conditional logic.
- Lists and collections.
- String processing.
- Functions and small scripts.

## Project Status

Training repository. It is useful as evidence of learning progress, but stronger
portfolio focus should go to complete application projects such as
`sokolov-web-lab`, `Aquento-filter` and `AmazonInventoryHub`.
